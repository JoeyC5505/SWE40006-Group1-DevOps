
# SWE40006 Group 1 — DevOps Project

## Project Overview
This project aims to design and implement a Level 4 DevOps pipeline for a Student Task Management System.

## Application
A Python Flask web application that allows users to create, view, update, complete and delete tasks.

## Technologies
- Git and GitHub — Version control and collaboration
- Jenkins — CI/CD automation
- VirtualBox and Ubuntu Server — Virtual server environments
- Docker — Containerization and deployment
- Python Flask — Web application
- pytest — Automated testing
- Prometheus — Server monitoring
- Grafana — Monitoring dashboard

## DevOps Pipeline
Developer → GitHub → Jenkins → Test Server → Production Server

Production performance is monitored using Prometheus and Grafana.

## Project Targets
- Level 1: Establish repository, CI/build, test and production servers.
- Level 2: Add production server performance monitoring.
- Level 3: Deploy and verify the Flask application.
- Level 4: Automate deployment after source-code changes.
